=================================================
 PROMPT GENERADOR DE SITIO - Ultimate Website
=================================================

**OBJETIVO:**
Crear un proyecto web completo desde cero llamado "Ultimate Website". El proyecto consiste en un backend con Node.js/Express que sirve una API RESTful, y dos frontends: un sitio público dinámico y un panel de administración completo para gestionar todo el contenido.

---
**1. ESTRUCTURA Y TECNOLOGÍAS**
---

- **Backend:** Node.js, Express, `mysql2/promise`, `jsonwebtoken`, `bcryptjs`, `nodemailer`, `mysqldump`, `multer`, `node-cron`, `helmet`, `cors`, `dotenv`.
- **Frontend (Admin):** HTML, CSS, y JavaScript modular (ESM). Usar Chart.js para gráficos y TinyMCE para edición de texto.
- **Frontend (Público):** HTML, CSS, y JavaScript modular (ESM).
- **Base de Datos:** MySQL o MariaDB.
- **Estructura de Carpetas:**
  /backend
    /config
    /controllers
    /middleware
    /routes
    /services
    /public/uploads
    /backups
  /frontend
    /admin
    /assets
      /css
      /js
      /images

**4. BACKEND**
---

1.  **Servidor (`server.js`):**
    - Configurar Express con middlewares de seguridad (CORS, Helmet con CSP).
    - Servir los frontends (público y admin) como archivos estáticos.
    - Registrar las rutas de la API (`/api` y `/api/public`).
    - Implementar un cron job que se ejecute cada minuto para publicar posts programados.

2.  **API RESTful:**
    - **Rutas Públicas (`/api/public`):** Endpoints para obtener configuraciones, menú, bloques, traducciones, posts, etc., sin necesidad de autenticación.
    - **Rutas Protegidas (`/api`):** Endpoints para la gestión desde el panel de admin, protegidos con JWT.

3.  **Autenticación y Seguridad:**
    - Crear endpoints para registro y login (`/api/users/register`, `/api/users/login`).
    - Generar tokens JWT al iniciar sesión.
    - Crear middleware `protect` para verificar el token en rutas protegidas.
    - Crear middleware `authorizeAdmin` para restringir rutas a usuarios con rol 'admin'.

4.  **Sistema de Caché (`cacheService.js`):**
    - Implementar un sistema de caché en memoria (NodeCache) para reducir las consultas a la base de datos en endpoints públicos.
    - Crear endpoints en el admin para limpiar la caché (`/api/cache/clear-all`, `/api/cache/clear-specific`).

5.  **Internacionalización (i18n):**
    - Endpoints para gestionar idiomas (CRUD).
    - Endpoints para obtener y actualizar las cadenas de traducción por idioma.
    - Los campos de texto principales en `posts` y `content_blocks` deben ser de tipo JSON para almacenar las traducciones.

6.  **Módulos de Gestión (Controladores y Rutas):**
    - **Posts:** CRUD completo, paginación, búsqueda por título.
    - **Secciones:** CRUD para la estructura del sitio.
    - **Bloques de Contenido:** CRUD completo y un endpoint para reordenarlos.
    - **Usuarios:** CRUD de usuarios con gestión de roles.
    - **Configuración (Settings):** Endpoints para obtener/actualizar configuraciones, subir logo e imagen de hero, y restaurar valores por defecto.
    - **Backups:** Endpoints para crear, listar, descargar y restaurar backups de la base de datos.
    - **SEO:** Endpoint para generar un `sitemap.xml`.
    - **Email:** Endpoints para guardar configuración SMTP y enviar un email de prueba.
    - **Comentarios:** Endpoints para listar, aprobar y eliminar comentarios.

7.  **Integración con IA (`aiService.js`):**
    - Crear un servicio para conectarse a una API de Ollama.
    - Implementar una función `generateSmartSummary` que tome el contenido de un post y genere un resumen corto y atractivo.
    - Integrar esta función en la creación/actualización de posts para guardar el resumen en la base de datos.

**5. FRONTEND - PANEL DE ADMINISTRACIÓN (`/admin`)**
---

1.  **Estructura:**
    - Crear una Single Page Application (SPA) con navegación por pestañas.
    - El acceso debe estar protegido por un formulario de login.
    - El diseño debe ser responsivo.

2.  **Dashboard:**
    - Mostrar tarjetas con estadísticas (posts, comentarios, etc.).
    - Implementar gráficos con Chart.js para: visitas, posts por categoría y posts por comentarios.
    - Añadir un botón para refrescar los datos sin recargar la página.

3.  **Pestañas de Gestión:**
    - **Estructura:** Interfaz de tarjetas para activar/desactivar secciones del sitio.
    - **Contenido:** Formulario dinámico que cambia según la sección seleccionada. Los campos de texto (título, descripción) deben generarse para cada idioma disponible. Usar TinyMCE como editor de texto enriquecido.
    - **Bloques Portada:** Interfaz para gestionar los bloques de la página principal con soporte para reordenamiento (drag-and-drop) y campos de texto multilingües.
    - **Apariencia:** Panel para personalizar colores, logo, tipografía, etc., con vista previa.
    - **Interacción:** Panel para moderar comentarios (aprobar/eliminar).
    - **Usuarios:** CRUD de usuarios con un selector para asignar roles ('admin' o 'editor').
    - **Copias de Seguridad:** Interfaz para crear, descargar, listar y restaurar backups.
    - **SEO:** Panel para editar metadatos globales y generar el sitemap.
    - **Email:** Formulario para configurar y probar los ajustes SMTP.
    - **Caché:** Botones para limpiar la caché del servidor.
    - **Internacionalización:** Panel para añadir/eliminar idiomas y editar las cadenas de traducción.

4.  **Permisos de UI:**
    - Ocultar las pestañas de gestión avanzada (Usuarios, Estructura, Backups, SEO, etc.) para los usuarios que no tengan el rol de 'admin'.

---
**6. FRONTEND - SITIO PÚBLICO (`/`)**
---

1.  **Contenido Dinámico:**
    - La página debe cargar dinámicamente desde la API pública:
        - El menú de navegación.
        - El logo, título y texto del pie de página.
        - Los colores y estilos personalizados.
        - El contenido de la sección "hero" (título, subtítulo, imagen).
        - Los bloques de contenido personalizados.

2.  **Internacionalización (i18n):**
    - Añadir un selector de idioma en la cabecera.
    - Al cambiar de idioma, el texto de la página (títulos, párrafos, etc.) debe actualizarse dinámicamente consumiendo las traducciones de la API.
    - La preferencia de idioma del usuario debe guardarse en `localStorage`.

3.  **Experiencia de Usuario:**
    - Implementar un interruptor para modo oscuro/claro.
    - Añadir un botón "Volver Arriba".
    - Implementar scroll infinito para cargar más contenido en las vistas de sección.
    - Añadir un formulario de búsqueda funcional.

**7. HERRAMIENTAS DE DESARROLLO Y MODELOS**
---

- **Postman:** Utilizado para probar y depurar los endpoints de la API RESTful durante el desarrollo.
- **Ollama:** Servicio para ejecutar localmente los modelos de lenguaje grande (LLM) como 'llama3', utilizado por el `aiService.js` para la generación de resúmenes inteligentes.
- **VS Code Live Server (o similar):** Utilizado para servir el frontend durante el desarrollo, lo que requiere una configuración de CORS y el uso de URLs absolutas en las peticiones a la API del backend.
    - Implementar scroll infinito para cargar más contenido en las vistas de sección.
    - Añadir un formulario de búsqueda funcional.
