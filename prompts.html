Estrategia de Desarrollo: Checkpoints

Objetivo: Establecer un punto de guardado o "checkpoint" antes de implementar una nueva funcionalidad compleja. Si la implementación falla, podemos revertir fácilmente al estado funcional anterior.

Proceso Sugerido:

  1. Antes de solicitar una nueva funcionalidad (ej. "Implementa X"), se puede solicitar: "Crea un checkpoint del estado actual del proyecto".
  2. El asistente confirmará que el estado actual es estable y está "guardado".
  3. Se procede con la nueva implementación.
  4. Si la nueva funcionalidad introduce errores difíciles de resolver, se puede solicitar: "Restaura el último checkpoint".

Nota: Este es un acuerdo de flujo de trabajo entre el usuario y el asistente de IA para simular un control de versiones simple durante la sesión de desarrollo.
